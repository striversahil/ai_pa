# Writing Skill — BUI

## Purpose
Take a researched topic in `content/drafts/` and draft a founder-voiced LinkedIn post for BUI. Source of truth: `BUI_BRIEF.md` Sections 4, 7, 8.

## Input
- Topic file in `content/drafts/` with `stage: draft` + `research_brief`
- Voice: `brand/voice.md` (first-person founder, practical, honest, specific, warm-but-direct)

## Process
1. **Read the brief.** Extract context, verified facts / `[NEED DATA]` items, audience, visual idea, risks.
2. **Write the post** using the Section 8 template:
   - **2 hook options** (Hook A / Hook B, 1-2 lines each) using Section 7 formulas (number+problem, mistake, buyer question, contrarian, before/after, behind-the-scenes, myth, checklist, story, honest refusal). Never "excited to share / happy to announce / in today's fast-paced world".
   - **Context:** 2-3 short lines (who, what, where)
   - **Core insight/story:** numbers, steps, or lesson (bullets where it helps)
   - **Takeaway:** what the reader should do/remember
   - **Soft CTA:** one question OR offer to help (never pushy)
   - **Hashtags:** 3-5 relevant only
3. **Constraints:** text posts 150-300 words; video captions 50-100 words; short lines, white space, no walls of text; numbers as digits; max 2-3 emojis (or none); carry forward `[NEED DATA]` / `[verify before posting]` flags — never resolve by inventing.
4. **Add to file:** `post_draft` section with Hook A, Hook B, post text, visual suggestion, hashtags, data-needed list.
5. **Frontmatter:** `written_at: YYYY-MM-DD`, `ready_for_edit: true`. If brief lacks verifiable material, set `writing_status: blocked` with what's missing.

## Brand voice checklist
- [ ] First-person founder, practical not fancy
- [ ] Specific number/example/detail present (or `[NEED DATA]`)
- [ ] No avoid-list buzzwords (game-changing, cutting-edge, world-class, revolutionary, synergy, leverage, next-gen, seamless, unlock, empower, solutions provider)
- [ ] No invented facts/customers; no guarantees; no competitor disparagement
- [ ] Paragraphs max 2-3 lines; Hindi/Hinglish only where the brief allows
