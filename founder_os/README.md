# Founder Assistant OS (Modular AI Executive Assistant)

This is a clean, modular backend application built with **Node.js**, **TypeScript**, **PostgreSQL (Prisma ORM)**, and an **OpenAI-compatible LLM abstraction**. It serves as an AI-powered executive assistant for a startup founder.

## 2. Prisma Database Schema

See the full definition in [prisma/schema.prisma](file:///home/sahildev/development/ai_pa/founder_os/prisma/schema.prisma):
* `Message`: Stores raw WhatsApp messages.
* `Email`: Stores synced emails.
* `Digest`: Stores structured JSON conversation digests generated by the AI.
* `Task`: Stores action items extracted from chats/emails.
* `FounderNote`: Stores generated morning briefings and daily EOD summaries.

---

## 3. Database Sync & Migrations

To initialize database schema on your Supabase instance:
1. Provide the Supabase database connection string in `.env` as `DATABASE_URL`.
2. Run the schema sync command:
   ```bash
   npx prisma db push
   ```
3. To seed mock messages and emails into the database for validation:
   ```bash
   pnpm run seed
   ```

## 4. Interfaces & Core Services

### Pluggable Email Provider Interface
Allows swapping Mock, Gmail IMAP, or Microsoft Graph providers without changing domain logic:
```typescript
export interface EmailProvider {
  fetchUnreadEmails(): Promise<Array<{ subject: string; sender: string; body: string }>>;
}
```

### AI Structured Output Interface
Validates JSON returned from the LLM when summarizing conversation batches:
```typescript
export interface SummaryOutput {
  chatName: string;
  summary: string;
  priority: 'low' | 'medium' | 'high' | 'urgent';
  category: string;
  sentiment: string;
  action_items: Array<{
    task: string;
    owner: string;
    deadline: string | null;
  }>;
  requires_founder: boolean;
  suggested_reply: string | null;
}
```

## 5. Scheduler Cron Jobs

Configured inside `src/modules/scheduler/service.ts` using `node-cron`:
* **Every 15 Minutes (`*/15 * * * *`)**: Runs the WhatsApp digest generator batch job.
* **Every 30 Minutes (`*/30 * * * *`)**: Synchronizes and saves emails from the provider.
* **Daily 8:00 AM (`0 8 * * *`)**: Generates morning briefing (schedule, urgent chats/emails, pending tasks).
* **Daily 7:00 PM (`0 19 * * *`)**: Generates End-of-Day Summary metrics and tomorrow's focus.

## 6. REST API Documentation

### Active Endpoints
* `POST /api/whatsapp/webhook` - Ingests messages pushed by the WhatsApp receiver.
* `GET /api/brief/latest` - Returns the latest morning brief or daily summary markdown.
* `GET /api/digests` - List of compiled chat conversation digests.
* `GET /api/tasks` - List of extracted action item tasks.
* `GET /api/messages/:chatId` - List of raw messages in a specific chat thread.
* `POST /api/ask-founder-ai` - Directly chat with the AI assistant referencing inbox context.

### Helper Trigger Endpoints (for testing/manual invocation)
* `POST /api/trigger/digest` - Manually triggers WhatsApp message digestion.
* `POST /api/trigger/email-sync` - Manually forces email sync.
* `POST /api/trigger/briefing` - Manually forces morning briefing generation.
* `POST /api/trigger/summary` - Manually forces evening summary generation.
